## The Nautilus OS Ecosystem

Nautilus is a lightweight, custom-engineered Operating System designed for performance and aesthetics. I am developing the entire suite of native applications to power the OS:

| Application | Role | Key Features |
| :--- | :--- | :--- |
| **Surfline** | Web Browser | Custom-built web navigation for the Nautilus environment. |
| **Riptide** | Sound Player | Dedicated audio management and playback system. |
| **Current** | System Monitor | High-density live graphs, quick process kill commands, memory alerts, and thermal throttling warnings. |
| **Tide** | Terminal Emulator | GPU-accelerated, tabbed shell sessions, split-pane support, and custom keybindings. |
| **Harbor** | File Manager | Keyboard-driven navigation, dual/single-pane modes, custom tag sorting, and quick file previews. |
| **Anchor** | Control Center | Central hub for display scaling, network/Bluetooth management, and system theme customization. |
| **TideEdit** | Quick Notes | Distraction-free, floating scratchpad with Markdown support, auto-saving, and direct file exportation. |
